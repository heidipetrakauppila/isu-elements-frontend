# ISU Elements - Frontend
Mobile-first React & TypeScript -sovellus taitoluistelijoiden henkilökohtaiseen kehityksen seurantaan.

## Tietoa projektista
ISU Elements auttaa taitoluistelijoita seuraamaan omaa kehitystään suhteessa kilpailusarjojen teknisiin vaatimuksiin. Sovelluksen avulla luistelija näkee, mitä elementtejä hallitsee, mitä harjoittelee parhaillaan ja mitä taitoja seuraava sarjataso edellyttää.

Pilottiversio keskittyy Ruotsin Ungdom 13 -sarjan luistelijan profiiliin.

## Käyttäjäongelma ja ratkaisu
**Ongelma:**  
Luistelijan on vaikea hahmottaa omaa kehitystään, koska tieto harjoitelluista elementeistä on hajallaan eikä etenemistä suhteessa sarjavaatimuksiin ole helppo seurata.

**Ratkaisu:**  
ISU Elements tarjoaa luottamuksellisen henkilökohtaisen profiilin, jossa luistelija voi seurata harjoittelemiaan ja hallitsemiaan elementtejä sekä omaa etenemistään kohti seuraavaa sarjatasoa.

## Keskeiset ominaisuudet
- Luistelijan profiili
- Elementtien seuranta
- Sarjavaatimusten tarkastelu
- Kehityksen visualisointi
- Nopea harjoituskuittaus
